# 網頁

```sh
python3 -m geo.pipe.server        http://127.0.0.1:8765/
python3 -m geo.pipe.server 9000   換個埠
```

不用裝任何東西（標準庫的 `http.server`）。

## 為什麼要有它

**命令列跑得動，跟看得見是兩件事。**

這條路上每一個安靜的失敗，在終端機上都長得像成功：文案 0、留言 0、
事實那一節永遠空的、那家沒報。每一個都跑完了、顯示完成、數字是零 ——
而「找到 0 筆」和「沒有去找」在畫面上一模一樣。

所以這一頁的規矩是三條：

```
每一格都印分母        「14 份都過」，不是「14」
零要自己叫            ⚠ 則事實 0　—— 不是安靜地印一個 0
讀不出來不是零        ⚠ 讀不出來（JSONDecodeError：…）
```

最後那條是 `topic.BROKEN` 那個坑的同一形狀：題目檔壞了四天沒人發現，
因為讀不出來就 `continue`。這裡不 `continue`，紅框列出來。

## 五頁

```
/                題目清單：九步的 ●◐○、壞掉的紅框、花了多少　·　開新題目
/story/<題目>     這一題：九步各跑過沒、產物數幾筆、按鈕跑一步、即時的 log
/effects         特效目錄：幾種、哪幾種畫得出來、要給什麼欄位
/rules           門檻和外觀（唯讀）
/spend           問了幾趟、各花多少
```

`◐` 是「跑過了，但上游比它新」（`paths.stale()`）。**它跟 `●` 要分得開**
—— 上游重寫過的話，這一步的產物是拿舊資料做的，檔案在、門會過，而成片
裡就是舊的畫面配新的聲音。

那排連結在 `skin.page()` 裡，所以**每一頁的位置一樣**。

## 沒有重做 look.html / watch.html

```
/page/<題目>/look     現產一份 look.html，轉過去
/page/<題目>/watch    現產一份 watch.html，轉過去
```

它們已經在做那件事，而且是**離線打開就能看的單一檔案** —— 關掉伺服器、
寄給別人都還在。這一頁只負責產生它們。

**同一件事做兩次，就會有一次是假的。** 而且每次都重產，因為那兩份是
快照，而畫面上看不出一份快照有多舊。

## 背景 job 不能當同步請求

舊專案在這裡印過「**寫好了：undefined**」：網頁打了一支會跑十二分鐘的
API，當場拿回 `undefined` 就印出來，而真正的工作還在跑。**那不會報錯**
—— HTTP 回 200、JS 也沒例外，只是畫面在說謊。

這裡的形狀：

```
POST /run          開一個 subprocess，馬上回 {"job": "<id>"}
GET  /job/<id>?from=N   回 {lines: [...], running: bool, code: null|0|1}
JS   run() → watch() → setTimeout(watch) → … → 跑完才解鎖按鈕、重讀頁面
```

子行程用 `python3 -u` 跑。**緩衝的話畫面會空白十分鐘然後一次噴出來**，
而那十分鐘正是最想看到「它還活著」的時候。

### `geo/checks/_web.py` 守的就是這件事

```sh
python3 -m geo.checks._web
```

三道，對著 `server.py` 的 `STARTS_JOB` 那張表和 `JS` 逐一比對：

```
一  開 job 的每一支都要在 run() 裡被打，而且只能被打一次
    run() 一定要接 watch()
    watch() 一定要問 /job/，而且要再叫自己
二  鈕的樣式只准有一份（skin.py 的 .btn）
三  顏色不准寫進 style 屬性 —— skin.py 換主題的時候改不到它
```

**加完種了四個違規試，而第二個沒叫。** 那一版查的是 `watch()` 裡有沒有
`setTimeout`，而 `watch()` 結尾本來就有一個 `setTimeout(reload)` 頂替了
—— 把真正的輪詢整行刪掉，門不會響。改成查它有沒有**再叫自己**，
四個才都叫。

**一道沒有被觸發過的門，跟沒有門一樣。** 這次是門自己犯了它要擋的錯
（同一形狀第二次，見 `geo/MISTAKES.md`）。

## 鈕只有一份

`geo/pipe/skin.py` 的 `CSS`。舊專案那邊六頁各抄一份、另外二十頁沒抄，
於是那二十頁露出瀏覽器預設的灰塑膠鈕 —— 不會報錯，只有人打開頁面才
看得到。

`look.py` 和 `watch.py` **沒有**改成用這一份，理由寫在 `skin.py` 開頭：
它們是兩種模式（白底的「過程」頁、黑底的「看片」頁），版面本來就不一樣，
而且**兩個都沒有鈕**。會重複的東西目前只有鈕，鈕只有一份。

## 影片要吃 Range

`watch.html` 整頁的用途是「點一行跳到那一秒」。**沒有 `Range` 的話
Safari 的 `<video>` 拖不動進度** —— 而這不會報錯，點了就是沒反應。

`/f/<題目>/<檔名>` 實作了 `206 Partial Content`。順便：那一支只給題目
資料夾底下的檔案，往上跳會 403。

## 破壞性的那一顆鈕

「重跑」會丟掉現在那一份答案，而問模型那幾步要再付一次錢。所以它是
**另一顆鈕、另一個顏色**，而且按下去要先確認。

「開新題目」遇到同名的資料夾直接 `raise`，不覆蓋 ——
那一種破壞（蓋掉一份已經跑了九步的題目）沒有任何產出可以抵。
