# 《紐約州、紐約市、紐約縣》地圖短影音逐格拆解

## 範圍與讀法

原檔為 **480 × 854、30 fps、72.214 秒**，並非 60 秒。下表涵蓋完整可播放影像的 0.0–72.0 秒，每 **0.2 秒**取一個觀察點；最後 0.2 秒另記於表後。表格內每個 `時間＝代碼` 都是一格，順序由左至右。字幕依原影片時間變動，但以下著重地圖畫面與視覺製作。

**重要限制：**0.2 秒取樣會漏掉更短的閃格；不能從輸出影片判定軟體品牌、原始 GIS 圖層或作者的工程檔。表內『地圖系統』指可在地圖/GIS 動畫工程內實作的操作；『後製』指通常在剪輯或動效軟體加上的元素。影片出現大量既有地圖畫面的回切，不能把每次切換都解讀為一次連續的 Google Earth 飛行。

## 主要視覺元件：來源歸類與重做方法

| 元件／動作 | 判斷 | 可執行的做法 |
|---|---|---|
| 深色衛星底圖、海陸紋理 | 地圖系統 | 使用同一衛星影像底圖；設定固定地理座標和 9:16 裁切。原廠牌無法從畫面確認。 |
| 地圖平移、尺度切換、局部推近／拉遠 | 地圖系統或後製攝影機皆可 | 在地圖工程對中心點及縮放級別設關鍵影格，或輸出高解析地圖後做 2D 位置/縮放。畫面多數是跳切，無足夠連續幀證明每一處都用了地圖導航。 |
| 紐約州紅色塊、五行政區粉／藍／橘／綠／紫、長島與周邊縣色塊 | 地圖圖層 | 載入州、縣、borough 多邊形；設定每一面填色與半透明度，疊在衛星底圖上。**上色屬作者加上的專題圖層，不是一般衛星底圖的固有顏色**。也可在 AE 用向量遮罩模擬。 |
| 州內縣界、五區外輪廓、紐澤西海域黃色虛線 | 地圖圖層 | 使用行政區及海域邊界線資料，指定描邊顏色、粗細與虛線；局部白邊也可後製描線。 |
| 地名雙語標籤與地理圖說 | 可能地圖標註，畫面看似另行排版 | 將地名設為隨地圖移動的標籤圖層；中文粗體加白描邊／陰影，英文小字。來源軟體不可識別。 |
| 紅色手繪圈、問號圖示、紅白圖釘、首府小黃塊、淺綠色中央公園條 | 額外標註圖層 | 在地圖工程中以點／線／面圖層實作，或用剪輯軟體疊 SVG／PNG；定位錨點必須跟著地圖移動。紅圈具有手繪感，較像額外圖形。 |
| 底部逐句白色字幕、黑邊，頻道字卡 | 後製 | 字幕與旁白按語句配時；頻道字卡是獨立全畫面鏡頭，非地圖操作。 |
| 跳切、白／暖色閃光、短暫柔焦／動態模糊 | 後製 | 用硬切換地圖預設鏡頭；少數轉場插入 2–4 幀白色或暖色半透明實色層與模糊。避免把所有跳切誤做成 zoom。 |

## 實作順序（可交給剪輯／動效程式）

1. 建立一份 9:16、至少 1080 × 1920 的衛星底圖地圖工程；將州、縣、紐約市五區、曼哈頓、長島兩縣、首府與標記另存為可切換圖層。確保取得底圖的使用與標註權限。
2. 建立 `洲級／州全景／州縣界／市五區／各區局部／曼哈頓／長島／紐澤西` 等 camera 預設；逐個輸出足夠解析度的片段或高解析靜幀。
3. 先依上方逐格表剪出硬切節奏，按實際配音對齊字幕，再對真正有連續移動的地方加入 position/scale 關鍵影格。
4. 再疊紅圈、問號、地圖釘、標籤、頻道字卡和少量 flash／模糊；地名標註跟地理位置走，底部字幕固定在畫面坐標。
5. 這份檔案是 72 秒；若目標成片必須 ≤60 秒，需要另行濃縮配音及刪減重複鏡頭，不能單靠加快所有地圖動作。

### 取樣精度提醒

逐格表以 0.4 秒接觸表人工辨識主要地圖構圖；中間的 0.2 秒格根據該影格與前後兩張參考影格的縮圖像素差，自動歸到較相近者。**它是視覺索引，不是逐幀偵測的精確切點表**。轉場邊界可能有約 0.2–0.4 秒誤差；對交付級逐幀 cut list 應再逐一檢查 30 fps 原影格。
