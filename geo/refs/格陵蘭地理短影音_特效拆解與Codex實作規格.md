# 格陵蘭地理短影音：特效拆解與 Codex 實作規格

參考影片：*Why Denmark Owns Greenland*，1080 × 1920、30 fps、80.83 秒。從原片每 0.2 秒取樣，共約 404 格；本文件挑選連續關鍵畫面作分鏡。時間為近似值，供定位與重現動作，不是原作者工程檔的精確關鍵影格。圖片均來自使用者提供的影片，僅供分析參考；實作時應重新製作素材。

## 核心判斷

畫面由兩套底圖（衛星／米色歷史地圖）、地理區域形狀、角色零件、圖示與文字、獨立雪地場景及後製轉場組成。**不能由成片確認原作者使用哪套地圖或動畫軟體。** 以下是建議給本機 Codex 的可重現方法，而非對原作者工作流程的斷言。

不要把取樣的 404 格當成要渲染的畫面清單。成片仍按 30 fps 連續渲染；地圖攝影機與各圖層在時間 `t` 計算狀態。取樣圖只用來驗證節奏與位置。

## 合成與座標設計

```
畫面固定：字幕、大標題、擦拭轉場
角色局部：眉、眼、嘴、手、皇冠 → 附著於地理區域
地理世界：國家遮罩、船、人物、旗幟、路線 → 同一攝影機
底圖：衛星或歷史地圖 → 同一攝影機
```

用統一的經緯度／投影座標。每一影格依序：將地點與區域投影到地圖平面；套用攝影機的平移、縮放與必要旋轉；把表情的局部錨點轉換到畫面；最後疊上畫面固定的字幕與轉場。歷史地圖與衛星地圖可以使用不同材質，但跨圖層的地理錨點必須一致。若底圖是預先渲染影片，應保存每一影格的攝影機變換，讓疊加圖層跟得上。

輸出建議：1080 × 1920、30 fps、H.264 MP4；繪製輪廓與文字時先用向量或高解析圖層，避免放大後鋸齒。先做無音訊的短段落驗證，再接配音與音效。

## 01｜衛星地圖推鏡、國家高亮與跨海引導線（0–4.4 秒）

![0–4.2 秒：從歐洲推近丹麥，填紅並以線條連到格陵蘭](storyboards/01_satellite_zoom.jpg)

**可見效果：** 衛星圖由歐洲快速推到丹麥；白色國界線可見；丹麥沿海岸變紅，白底標籤出現；細粉紅線朝格陵蘭延伸，攝影機跟著移動。這是地理鏡頭加獨立的填色、描線與標籤。

**實作：**

1. 以衛星底圖建立連續的攝影機關鍵影格：世界／歐洲 → 北歐 → 丹麥 → 北大西洋 → 格陵蘭。對中心和縮放分別做緩動；不需要逐格手工截圖。
2. 取丹麥多邊形，加入小島與洞；製作紅色填充、細白邊及白底文字標籤。用透明度或裁切遮罩讓紅色在約 2.2–2.6 秒出現。
3. 粉紅線是一條地理路徑，以 path trim／dash offset 描出；攝影機移動與描線同步。線可固定於地圖世界，不應固定在螢幕像素上。
4. 對快速跨海段加適量 motion blur。轉場模糊可在合成階段施加，不必讓地圖 SDK 處理。

**驗收：** 暫停在丹麥任何一幀，紅色填充均不漂離海岸；線的起點跟著丹麥一起移動。

## 02｜島嶼輪廓變成會說話的角色（4.4–8.6 秒）

![4.6–7.0 秒：格陵蘭輪廓上的眉眼嘴與手臂逐步出現](storyboards/02_greenland_character.jpg)

**可見效果：** 格陵蘭紅色區域保留細碎海岸及部分白色冰雪線；標籤退去後，眉、眼、嘴和細線手臂出現並改變情緒。攝影機拉遠，角色仍貼在島上。

**實作：**

1. 以格陵蘭陸地多邊形作紅色身體。若要接近參考片的邊緣，另疊一層來自底圖的冰雪／海岸線細節，或沿遮罩生成不規則白色細線；不要用單一平滑輪廓蓋住峽灣。
2. 五官不要烘在紅色形狀內。設 `eyes`, `brows`, `mouth`, `arms` 子層，錨定在島嶼局部座標；準備 `neutral`, `annoyed`, `curious`, `happy`, `sad` 等姿勢。
3. 眼神移動靠瞳孔平移；眨眼可縮放眼白／替換眼皮；口型用少量圖形切換。手臂用 Bézier 線條，端點固定在身體局部位置。
4. 島嶼輪廓、五官與手臂共同繼承地圖攝影機；角色局部動畫再疊於其上。必要時給五官的線寬設縮放下限，以免拉遠後完全消失。

**驗收：** 在 5.4 與 6.4 秒比較，五官相對格陵蘭的地理位置穩定；只改表情與整組縮放。

## 03｜歷史地圖、航船與人口分布（8.6–17.6 秒）

![8.8–16.8 秒：換成歷史地圖，船航行、人口圖示逐個出現](storyboards/03_viking_route.jpg)

**可見效果：** 衛星圖經快速模糊換成米色陸地、淺藍海洋的歷史地圖；維京船由海面移向格陵蘭，人物圖示分布在島嶼北部和西南岸。地圖同時推拉、平移。

**實作：**

1. 另外建立一套歷史底圖：統一的米色陸地、紙張肌理、海洋色、輪廓筆觸。與衛星底圖共用投影和地理錨點，或在切鏡時轉換坐標。
2. 船是透明圖示或簡單 rig，沿經緯度路徑插值；姿態可略微上下浮動和搖擺。人物是地理錨點圖示，分批淡入／彈入，而非嵌進底圖。
3. 「2500 BC」「985 AD」等大型文字與底部字幕分別管理；日期若要跟著地點移動，用地理錨點，字幕則固定於畫面。
4. 衛星圖退場與歷史圖入場可用短暫的方向性模糊或直接切換；不要試圖在同一材質上漸變成完全不同地圖風格。

**驗收：** 船進港與居民所在位置在鏡頭移動時不滑動；歷史圖的海岸線與定位圖示一致。

## 04｜離開地圖的雪地插畫，放射模糊返回（17.6–25.0 秒）

![17.4–25.0 秒：地圖切入雪地角色場景，之後放射模糊回到地圖](storyboards/04_scene_transition.jpg)

**可見效果：** 雪山、地面和兩名維京角色佔滿畫幅；人物有頭部與身體的簡單變化；彩色「MARKETING」逐字／整組彈出；兩端以放射模糊連到地圖。

**實作：** 雪景作獨立背景，人物分成身體、頭、手等透明層做小幅位移與旋轉；文字逐字縮放和錯位。入退場時對舊鏡頭施加 radial zoom blur，同時讓新鏡頭放大／縮回並交疊數幀。地圖系統不參與這段的角色渲染。

**驗收：** 在 17.6 與 24.8 秒看見的是整幅鏡頭的放射拉伸，而非雪地角色在地圖上移動。

## 05｜招牌、抵達者、聚落與局部地圖推拉（25–33.8 秒）

![25–32 秒：招牌固定在格陵蘭，抵達者與聚落標記接連登場](storyboards/05_settlement_map.jpg)

**可見效果：** 回到歷史地圖後，格陵蘭上有招牌；鏡頭推近島嶼，人物站在南部；其後拉回，定居點以小橘色標記顯示。

**實作：** 招牌、人物和聚落分別建立錨點；關鍵影格控制出現時刻、比例及輕微彈跳。攝影機以格陵蘭南部為焦點推拉。遠景時圖示按設定縮小或保持最小可讀尺寸，不能讓全部圖示永久等大。

**驗收：** 招牌與島內地理位置在 25–29 秒保持一致，聚落圖示在 31–33 秒落於正確區域。

## 06｜1261：格陵蘭沿輪廓連續變色（36.6–37.4 秒）

![36.2–38.0 秒：格陵蘭由底圖色，經白、淡藍轉為深藍](storyboards/06_greenland_1261.jpg)

**可見效果：** 格陵蘭陸地在相同輪廓內先閃白、再淡藍、再深藍；「1261」一直位於島上；冰島也呈同一陣營的藍色。細碎海岸線沒有跟著消失。

**實作：** 以格陵蘭地理多邊形作單一 alpha mask，對 mask 內填色設定顏色關鍵影格（紙色 → 白 → 淡藍 → 深藍）。將輪廓線和地形細節放在色塊上方；年份文字單獨一層。若要求歷史精確性，政治歸屬狀態與日期應先人工核對資料來源。

**驗收：** 36.8、37.0、37.2 秒的色塊外形完全相同，僅顏色與鏡頭尺度不同；沒有顏色溢出海面。

## 07｜多國版圖重組成卡爾馬聯盟（40–44 秒）

![40.6–43.4 秒：挪威、瑞典、丹麥分色，紅色逐步覆蓋成聯盟](storyboards/07_kalmar_union.jpg)

**可見效果：** 挪威藍、瑞典黃、丹麥紅；紅色區域從斯堪地那維亞局部擴張，最後多國同色；「Kalmar Union」斜放在北歐陸地上。

**實作：** 以各歷史區域獨立 SVG/path 表示，為時間點建立 `owner/color` 狀態；用局部遮罩擦入和填色過渡表現聯盟形成。斜文字可定位於地圖世界並隨鏡頭旋轉／縮放。不要用當代國界資料直接聲稱是精確的歷史邊界；先確認敘事需要的時期形狀。

**驗收：** 各區填色相接處無空隙與重疊；紅色擴張時海岸外仍是海洋。

## 08｜北歐輪廓擬人化、手勢與哥本哈根皇冠（44–52.4 秒）

![44.2–52.2 秒：紅色聯盟長出五官與手，鏡頭移向哥本哈根，之後角色不滿](storyboards/08_country_face.jpg)

**可見效果：** 聯盟紅色形狀上疊一雙眼睛、眉與嘴；黑色細線手臂伸到丹麥附近，白手套出現；鏡頭推近哥本哈根的皇冠圖示；之後拉回，北歐輪廓繼續做表情。

**實作：** 國家輪廓本身依地理座標繪製；臉部零件以局部錨點定位。手臂可用二次／三次 Bézier 路徑，每幀更新肩、肘、手點；手套和皇冠可用 SVG。皇冠固定在哥本哈根地理位置；畫面推近時要跟隨攝影機，而不是固定畫面中心。

**驗收：** 推到 48.2 秒時皇冠仍指向哥本哈根；拉回 49.6 秒時臉部仍貼在北歐紅色區域。

## 09｜版圖分裂、白色擦拭、亮光與皇冠（52.4–63.8 秒）

![52.4–62.2 秒：區域分色、白色擦拭、分裂亮光、五官與皇冠](storyboards/09_split_norway.jpg)

**可見效果：** 紅色區域逐步轉為紅／黃／藍；約 53.4 秒有白色彎曲形狀掃過畫面；拿破崙戰爭後，丹麥與挪威交界有橙白亮光；挪威的大眼睛看向小型丹麥角色，皇冠落在挪威與瑞典區域。

**實作：** 分裂用幾個區域遮罩的顏色與透明度狀態切換。白色擦拭是覆蓋整畫面的 shape layer/matte，可加邊緣旋轉，不必動地圖幾何。亮光沿指定邊界曲線使用發光線條與短命粒子；皇冠、眼睛、手各自獨立動畫。這一節要注意層級：地圖 < 色塊 < 亮光 < 角色 < 字幕 < 白色擦拭。

**驗收：** 白色形狀掃過的是全畫面；亮光貼著分界，不隨字幕位置移動。

## 10｜歷史地圖回衛星圖，島嶼旗幟與時間線（64–73 秒）

![66.6–72.8 秒：歷史地圖模糊切衛星圖，冰島旗幟與年份接力](storyboards/10_islands_timeline.jpg)

**可見效果：** 格陵蘭從歷史地圖的淡色轉紅，隨即模糊切回衛星圖；攝影機推至冰島與法羅群島，島嶼內有國旗，附近出現 1944／1948；回格陵蘭則依序顯示 1979、2009。

**實作：** 先在歷史底圖完成色塊狀態，再用短暫 zoom blur 切換到相同地理中心的衛星底圖。旗幟裁在島嶼輪廓內，年份與描述用地理錨點及排版規則放置；鏡頭在各島間平移。年份字和國旗可以留在地圖世界，但底部字幕固定畫面。

**驗收：** 切換前後格陵蘭、冰島、法羅群島的相對位置連續，沒有跳到不相干的地圖視角。

## 11｜結尾雙角色表情對話（73–80.8 秒）

![73–79.8 秒：格陵蘭由喜轉悲，歐洲另一角色抬眼回應](storyboards/11_final_dialogue.jpg)

**可見效果：** 格陵蘭由得意笑臉變成擔憂、沮喪，再向右看；歐洲一角長出眼睛，兩者隔著北大西洋對望。大部分地圖底圖幾乎靜止，節奏靠角色表情推進。

**實作：** 將表情狀態表寫成時間事件：眉角、瞳孔方向、嘴型、手臂曲線分別插值。第二角色的五官附著在其地理區域。可以只使用 5–8 個清楚的表情姿勢，配合 0.1–0.3 秒的過渡，避免逐幀手繪。

**驗收：** 地圖不動時，情緒仍能由眉、眼、嘴的變化辨識；兩組眼神方向能形成互看關係。

## 本機 Codex 建議的工程拆分

1. **資料與資產**：地理 GeoJSON／SVG；兩套底圖；角色五官 SVG；船、人物、旗幟；雪景角色素材。記錄各素材來源與授權。參考影片的畫面不可直接當自己的成品底圖使用。
2. **地圖渲染器**：將經緯度投影至地圖平面，輸出相同攝影機下的衛星／歷史底圖與區域遮罩。可用 MapLibre GL JS 或其他可程式控制的地圖渲染方式；底圖服務與授權需依實際素材決定。
3. **2D 動畫引擎**：用 SVG／Canvas／WebGL 或合成軟體腳本管理角色、道具、遮罩、字幕和轉場。若以程式輸出，可用瀏覽器渲染每個時間點，並透過 FFmpeg 編碼；這是以時間參數渲染連續影片，不是人工製作幾百張固定截圖。
4. **時間線資料**：每一鏡頭定義 `start/end`、底圖、攝影機關鍵影格、地區狀態、地理圖示、角色姿勢與轉場。允許幾個事件同時進行，而非每句旁白只顯示單一畫面。
5. **驗證**：先完成 3–8 秒的衛星圖／格陵蘭角色，再完成 36–38 秒的輪廓變色，最後做 17–25 秒跨場景轉換。檢查海岸線對齊、圖層順序及 30 fps 動態，不只比對靜態分鏡。

## 建議的最小時間線格式

```yaml
scene: greenland_1261
time: [36.2, 38.0]
basemap: historical
camera:
  - {t: 36.2, center: [-40, 64], zoom: 1.0}
  - {t: 37.4, center: [-42, 71], zoom: 1.25}
regions:
  greenland:
    colors:
      - {t: 36.6, value: '#d5c7a0'}
      - {t: 36.8, value: '#f7edf0'}
      - {t: 37.0, value: '#9fafd3'}
      - {t: 37.2, value: '#2c5a9d'}
overlays:
  - {type: year, text: '1261', anchor: [-42, 72], in: 36.2, out: 37.8}
```

這些經緯度、縮放與色碼只是展示資料結構，**不是從影片反推的精確值**。正式製作應依所選投影、底圖與畫面構圖重新校準。

## 難度與優先順序

最難的是**精確地理遮罩與攝影機同步**，其次是歷史邊界資料和好看的角色表演。白色擦拭、文字、船沿路徑移動和放射模糊較容易做。先把 0–8 秒及 36–38 秒做成兩個短樣片：它們分別驗證衛星地圖上的角色對齊，以及歷史地圖上的國家填色；通過後再擴展到完整 80 秒。
