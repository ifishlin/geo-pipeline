## 說好要做、還沒做的

### 地理系統的文案也要分片型（使用者 2026-09-26 交代）

**現在這 11 種 role 偷偷假設了「故事有一條時間線」。** 表上寫著
起點／事件／因果，而那三種只有編年的故事才有。

拿「紐約州／紐約市／紐約縣」那種冷知識去跑，模型**照樣填得出來** ——
它不會說做不到，它會把「分辨三個範圍」硬塞進起點→事件→因果，演一個
不存在的形狀。跟「叫它填座標，它給一份中心差三度的答案」是同一回事。

那種題目要的是別種 role：分辨、範圍、誤會、舉例。而 `dated_most 30%`
那道門在沒有年份的題目上形同虛設。

形狀照舊路踩出來的來（`assets/rules.json` 的 `structure.voices`）：

```
rules.json
  roles          一份共用的底 —— 反常、接話、更正、吐槽、翻面、收
                 （這幾種跟有沒有時間線無關）
  kinds.<片型>   只寫覆蓋，不是各自一份完整的表
                   history  加 起點／事件／因果，dated_most 30%
                   trivia   加 分辨／範圍／誤會／舉例，dated_most 0
story.json
  kind: "history"
```

**不准每種片型各一份完整的表** —— 舊路「同一份直述四個片型各一份，
而 unfold 那份改過、另外三個還在犯它修掉的錯」就是這麼來的。

**什麼時候做：等第二個題目，而且要是沒有時間線的那種。** 現在只有一個
題目，「哪幾種是共用的底」是猜的；分錯之後兩份表會各自漂走，比不分更貴。

## 花錢的地方（重要）

使用者的一個 team 額度用完了，正在換另一個。**這條路最貴的就是模型呼叫**：

```
spine       2–4 分鐘
script      三趟：10–25 分鐘 ＋ 2 分鐘 ＋ 3 分鐘
storyboard  3–5 分鐘
壓片        9 分鐘（不花模型的錢，但佔機器）
```

我一個晚上跑了十幾輪。**動手之前先問**，尤其是 `script --again`
（那一趟最久）。

三個旗標可以只重跑一小段：

```
--again     那一步整個重問
--parts     只重問「配角色」那一趟
--narrate   只重問「接起來」那一趟
--plain     停在旁白稿，不配角色（先看故事站不站得住）
```

## 三條這條路上學到的規矩

**一、模型只講話，程式算數字。** 座標、縮放、秒數、字幕折行全部是算的。
模型看不到畫面，叫它填座標它不會說做不到，它會給一份格式正確、
中心差三度的答案。

**二、那支參考片只是參考。** 使用者講了三次。我一度把它每個比例都訂成
目標（年份 11%、主角 42%、對白 39%），那樣做出來的每一支都是它的複製品。
現在門一律是「擋明顯壞掉的」，不是「長得像它」。

**三、問模型之前先跑 `python3 -m geo.check`。** 一個晚上三次 NameError
都是在模型答完之後才炸，最貴一次 12 分鐘。那支用 AST 掃「函式裡用了
不存在的名字」，零誤報，已經接在 `make` 上。
