## 花錢的地方（重要）

使用者的一個 team 額度用完了，正在換另一個。**這條路最貴的就是模型呼叫**：

```
spine       2–4 分鐘
script      三趟：10–25 分鐘 ＋ 2 分鐘 ＋ 3 分鐘
storyboard  3–5 分鐘
壓片        9 分鐘（不花模型的錢，但佔機器）
```

我一個晚上跑了十幾輪。**動手之前先問**，尤其是 `script --again`
（那一趟最久）。

三個旗標可以只重跑一小段：

```
--again     那一步整個重問
--parts     只重問「配角色」那一趟
--narrate   只重問「接起來」那一趟
--plain     停在旁白稿，不配角色（先看故事站不站得住）
```

## 三條這條路上學到的規矩

**一、模型只講話，程式算數字。** 座標、縮放、秒數、字幕折行全部是算的。
模型看不到畫面，叫它填座標它不會說做不到，它會給一份格式正確、
中心差三度的答案。

**二、那支參考片只是參考。** 使用者講了三次。我一度把它每個比例都訂成
目標（年份 11%、主角 42%、對白 39%），那樣做出來的每一支都是它的複製品。
現在門一律是「擋明顯壞掉的」，不是「長得像它」。

**三、問模型之前先跑 `python3 -m geo.check`。** 一個晚上三次 NameError
都是在模型答完之後才炸，最貴一次 12 分鐘。那支用 AST 掃「函式裡用了
不存在的名字」，零誤報，已經接在 `make` 上。
