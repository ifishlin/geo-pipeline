# 參考片

別人的頻道，拿進來研究節奏和做法用的。**一個資料夾一支片**，裡面放得到的
每一樣：影片、音訊、逐字稿、存下來的頁面。

收進來之前這些東西散在四個地方（repo 根目錄、`四處觀察/`、`work/四處觀察/`、
桌面），要湊齊一支片得走四趟。

上面一層是頻道。`待歸類/` 是還不知道出自哪個頻道的 —— **不知道就寫不知道，
不要猜一個看起來合理的歸屬**，猜錯了不會報錯。

## 字幕是機器聽的，不是官方的

逐字稿是 faster-whisper `medium` 跑出來的 TSV（`起	迄	字`），**不是頻道的
原始字幕** —— 那幾支的 mp4 裡沒有字幕軌，也沒抓到 YouTube 的字幕檔。

**整批同一個模型**，混大小的話品質差異在畫面上是看不出來的 —— 字都長得像字。
英文那支的語言是寫死的，不讓它猜：猜錯不會報錯，只會交出一份「聽起來像那個
語言」的稿子。

```
秒數    可信。要拿它當切點的依據沒問題
字      要校。中文那幾支看得出錯，例如紐約那支的「全州移動擁有62個縣」（共）、
        「布蘭克斯區」（布朗克斯）、「紐約州的幾個角落」（一個）。
        英文那支的專有名詞目前看起來都對
```

**拿它的字去對地名之前要先校過。** 地名正是這個題材最會錯的地方，而錯了
不會報錯 —— 只會畫出一張指著別的地方的地圖。

## 這一份怎麼來的

`reference/` 整個不進版控（拿進來的是別人的東西），只有這一份 README 進。
表上的數字是量出來的，重跑產生它的那支腳本就重新量一次 —— 手寫的話它會
慢慢跟目錄分家，而且沒有人會發現。
