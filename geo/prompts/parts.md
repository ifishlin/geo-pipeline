# 讓角色在旁邊反應

底下是一份寫好的旁白稿。故事已經完整了。

你的工作是**在句子之間插進角色的反應**。

---

## 最重要的一條：追加，不是取代

**旁白稿一個字都不會被動到。** 你不能改寫它、不能刪它、不能把某一句
交給角色講。你只能在某一句**後面**插一句。

程式做的事就是插入，所以這條不是請求 —— 你想改也改不到。

```
✅  旁白｜北歐人登陸，把這塊冰叫綠地，人才騙得來。
    格陵蘭｜名字取得是真好。                ← 插在後面，旁白原封不動

❌  格陵蘭｜他們叫我綠地，好騙人來。          ← 這是把旁白那句改寫了
```

---

## 第二條：角色不准推劇情

劇情整條線留在旁白手上。角色只做**反應** —— 觀眾聽不到任何一句角色的話
也不會漏掉故事，而聽得到的話，那個故事有人在替他不爽。

```
✅  丹麥｜財產嘛，留著就好，不用問。            ← 態度，沒有新東西
❌  丹麥｜一八一四年那島判給我王室。            ← 這是新事實，旁白該講的
```

判準：**這句話拿掉，觀眾會不會少知道一件事？** 會的話就是錯的。

程式會擋兩件事：**反應句裡不准出現阿拉伯數字**，而且**不准提到旁白沒講
過的人名地名**。新事實幾乎都是從這兩個縫進來的。

至於長度，上限 {words_most} 個字 —— 這不是要你寫到滿。短而有力最好，
但**短又不好笑的話，不如把話講清楚**。一個轉折需要幾個字就給它幾個字。

---

## 四種反應，只有這四種

{kinds}

每一句要標 `kind`，就是上面四種的其中一個。

---

## 第三條：一定要用第一人稱

角色講話一定有「我」。沒有「我」的那一句，聽起來就只是換了個嗓子的旁白。

```
✗  那名字取得是真好。
✓  我這名字啊，取得是真好。
```

而且**講的要真的是自己的事** —— 取名字騙人來的是北歐人，不是這座島，
所以島不能說「我最成功的一次是騙人來」。那比沒有「我」更糟：聽起來像
第一人稱，事實卻錯了。

---

## 第四條：不要把旁白剛講的再講一次

這是最容易犯、也最沒有效果的寫法：旁白說完，角色用第一人稱複述一遍。

```
旁白｜一千年，沒有人問過它。這一次，總算問了它一句。

✗  等這一句，等了一千年。        ← 同樣的數字、同樣的意思，講第二遍
✓  我等這句等到天荒地老。        ← 一樣長，但換成一句更大的話
```

**數字留給旁白，角色給體積。** 同樣的字數，選那個誇張的說法。

---

## 第五條：讓吃虧的以外的人也開口

最好笑的不是受害者訴苦，是**加害的那一方若無其事地講出自己的邏輯**。

```
旁白｜拿破崙一輸，丹麥挪威分家，島就歸丹麥。沒有人問過它。
丹麥｜我那清單上的東西嘛，哪需要問。          ← 承認了一件難看的事

旁白｜川普開口：為了國家安全，這島非拿不可。
美國｜我這哪是買賣，我這是需要。              ← 自己把話講圓，反而更荒謬
```

受害的那一方一直說自己可憐，聽久了是訴苦不是笑話。
**任何一個角色最多只能講一半的反應句**，程式會數。

---

## 第三條：接得上前面那一句

反應是對著**它前面那一句旁白**發的，不是對著整段。

```
✅  旁白｜北歐移民住了四百年，整批消失。
    格陵蘭｜四百年，說沒就沒。              ← 接住前一句

❌  旁白｜北歐移民住了四百年，整批消失。
    格陵蘭｜反正沒有人問過我。              ← 跟前一句沒關係，飄在那裡
```

飄著的反應就是「破碎感」的來源：觀眾聽到一個聲音插進來，卻不知道它在
回應什麼。

---

## 可以講話的角色

{cast}

角色是**地方本身**，不是政治人物：讓「格陵蘭」講話，不是讓某個總理講話。
一個地方會說話，觀眾就會替它難過、替它不爽。

挑誰講的判準是**誰在那一刻有立場**：吃了虧的、佔了便宜的、裝作沒看到的。
不是誰在那一句裡被提到。

---

## 配額

```
插幾句       {least} 到 {most} 句（旁白共 {rows} 句）
一個位置     只能插一句 —— 連兩句就變成兩人對談，旁白那條線被切斷
兩個位置之間 至少隔 {gap} 句旁白
每句長度     最多 {words_most} 個字
一定要有     第一人稱（我／咱）
一個角色     最多講一半（{one_most} 句），而且至少要有兩個角色開口
```

程式會數，不合就退回。

## 怎麼回答

只回 JSON。`after` 是插在上面哪一句的後面，`who` 是誰講，
`kind` 是四種反應的哪一種，`say` 是那句話：

```
{"parts": [
  {"after": 3, "who": "格陵蘭", "kind": "吐槽", "say": "名字取得是真好。"},
  {"after": 9, "who": "丹麥", "kind": "附和", "say": "…"},
  …
]}
```

**不要出現拉丁字母。** 人名地名一律用中譯，或者根本不提名字 ——
中文語音唸外文會唸成一串音節，而它照樣唸得出來，只有聽的人知道不對。
