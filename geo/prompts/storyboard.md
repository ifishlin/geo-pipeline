# 這支片的分鏡

一支**地圖短影音**。畫面只有一張地圖：鏡頭在上面滑動、把某幾塊地塗上顏色。
沒有照片、沒有實拍、沒有卡片。

你決定**每一段要看到哪裡**，以及**哪幾個接縫是真的斷點**。

---

## 最重要的一條：鏡頭是滑的，不是切的

觀眾看的是一張地圖。地圖一直跳，人會暈，而且會失去「這些地方彼此在哪」
的感覺 —— 而那正是地理短影音唯一能給的東西。

```
預設   鏡頭從上一個地方滑到下一個地方。觀眾看得見自己怎麼過去的
例外   硬切。只在真的斷掉的地方用
```

什麼叫真的斷掉：

```
換時代      「1946 年」→「然後是 2025 年」
抖包袱      前一句鋪、這一句翻
跳到無關的地方   兩個地方隔著半個地球，而這句話沒有在講「從這裡到那裡」
```

**其他一律用滑的。** 你不用寫怎麼滑、滑多久 —— 那是程式算的。你只要在
真的該斷的地方標 `cut`。

---

## 第二條：一格要夠久

鏡頭要滑得動，就得有時間。一格**兩到三秒**是舒服的；一秒以下的格子
滑不動，只能硬切，而連續幾個那種就是在閃。

這支片 {seconds} 秒。**大約 {aim} 格**是對的 —— 不是 {count} 格
（那是一句一格），更不是一百格。

一句話裡面可以完全不換畫面。**一段話共用一個地方，是正常的。**

---

## 第三條：畫面要在故事講的位置

這一段在講丹麥，畫面上就要看得到丹麥。聽起來理所當然，但很容易破功 ——
講到「丹麥拒絕了」的時候鏡頭還停在格陵蘭，觀眾就得自己想像。

程式會檢查：**一句台詞裡提到的地名，必須在那一格看得到**。
對不上會被退回。

---

## 你只給名字和詞，不要給數字

```
要給      地方的名字（「格陵蘭」）、句子裡的某個詞（「公投」）
不要給    經緯度、縮放級數、秒數、像素
```

你看不到地圖，算不準；而外框查得到，算得準。給了座標會被丟掉。

## 每一格的欄位

```
line     這一格從第幾句開始（下面的編號）
word     在那一句的哪個詞上切進來。空字串＝那句話一開頭
see      要看到哪些地方。相機由它算出來
tint     要塗色的地方。不寫＝跟 see 一樣
mark     要標記哪些點（會畫一個標記和名字）。可以是空的
cut      true ＝ 這裡硬切。不寫或 false ＝ 鏡頭滑過來
why      這一格為什麼存在 —— 一句話
```

`word` 要**一字不差**地出現在那一句裡，而且在那句話裡只出現一次。

`see` 放兩個地方，相機會退到兩個都看得見 —— 講「這兩邊的關係」的時候
用它。但**大小差很多的兩個放一起，小的那個會變成一個點**（丹麥配格陵蘭
就是這樣），那種情況下小的那個改用 `mark`。

## 怎麼回答

只回 JSON，不要解釋：

```
{"shots": [
  {"line": 0, "word": "", "see": ["格陵蘭"], "cut": true, "why": "開場，先立在島上"},
  {"line": 4, "word": "北歐人", "see": ["北歐", "格陵蘭"], "why": "從那邊過來"},
  …
]}
```

照時間順序。**第一格一定是 `line: 0`、`word: ""`。**

寫完自己數一次：幾格？如果超過 {most} 格，那就是切太碎了，
回去合併 —— 一段話共用一個地方是正常的。
