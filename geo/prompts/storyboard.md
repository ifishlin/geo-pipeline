# 替這支片的每一句挑畫面

這是一支**地圖短影音**。整支片的畫面只有一樣東西：一張地圖，鏡頭在上面移動、
切換、把某幾塊地塗上顏色。沒有照片、沒有實拍、沒有卡片。

你的工作是替每一句話決定**要看到哪裡**。

---

## 你只給名字和詞，不要給數字

```
要給      地方的名字（「格陵蘭」）、句子裡的某個詞（「公投」）
不要給    經緯度、縮放級數、秒數、像素
```

相機在哪、縮放多少、第幾秒切，全部由程式從你給的名字算出來。
**你給一個座標的話它會被丟掉**，而且那一格會被當成你沒有作答。

理由很簡單：你看不到地圖，算不準；而外框查得到，算得準。

---

## 一句話可以換好幾次畫面

這種片子的節奏是**一句裡切兩三次**，不是一句配一張圖。參考頻道 72 秒的片
切了大約 130 次，平均 0.55 秒一次。

所以每一句給的是一串「切點」，每個切點說：切到哪個畫面。

切點的位置用**句子裡的一個詞**來指，不是秒數 —— 程式會把它對到那個詞被
唸出來的時間。詞要**一字不差地出現在那句話裡**，而且在那句話裡只出現一次。

第一個切點的 `word` 留空字串，表示「這句話一開始就切」。

---

## 可以用的地方

只有這些。**不在清單上的名字會被擋下來**，不要自己想一個。

{places}

---

## 每一個切點的欄位

```
word     在這個詞上切。空字串＝這句話開頭就切
see      要看到哪些地方（一個或多個名字）。相機由它算出來
mark     要標記哪些點（會畫一個標記和名字）。可以是空的
tint     要塗色的地方（會填色）。不寫的話預設跟 see 一樣
why      這一格是為了什麼 —— 一句話，給人看的
```

`see` 決定鏡頭裝得下什麼。想看整個歐洲就寫歐洲共同體，想只看格陵蘭就
只寫格陵蘭。**兩個大小差很多的地方一起 see，小的那個會變成一個點** ——
真的要那個效果就寫，不然分兩格。

（不是旁白），那種通常是這支片的笑點，畫面可以跟著俏皮一點。

---

## 怎麼回答

只回 JSON，**不要任何解釋**：

```
{"shots": [ {"line": 0, "cuts": [ … ] }, … ]}
```

每一句都要有一筆，`line` 是上面的編號。一句至少一個切點。

寫之前先想：這支片 {seconds} 秒、{count} 句。全部加起來如果只有 {count} 個
切點，那就是一句一張圖 —— 那是另一種片子的做法，不是這一種。
