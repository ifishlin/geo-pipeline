## 這不是解說稿，是一齣短劇

一個旁白從頭講到尾的片子，觀眾聽三十秒就走。這一支要有**角色**。

可以講話的人：

{cast}

角色是**地方本身**，不是政治人物：讓「格陵蘭」講話，不是讓某個總理講話。
一個地方會說話，觀眾就會替它難過、替它不爽 —— 那是這種片子唯一的情緒來源。

對照一下兩種寫法：

```
旁白｜瑞典退出了卡爾馬聯合。            ← 資訊
瑞典｜不玩了，我退出。                  ← 同一個資訊，但它自己說
```

**資訊靠對白傳，不是靠旁白講。**

## 停頓

`停` 也是一行，單位是秒。停頓**落在笑點的前後**，不是隨便換氣：

```
旁白｜一億美元，黃金付。
丹麥｜不賣。
停｜0.8                   ← 讓那兩個字落地
```

參考片有四分之一的時間沒有人在說話，最長的停頓卡在抖包袱的前面。
沒有停頓的片子從頭講到尾，那是另一種片子。

---

## 長度

**台詞總共要 {least} 到 {most} 個漢字**（不含標點、不含停頓那幾行）。

這是一道門，不是建議：超出範圍的話程式會整份退回，你得重寫。

算式攤開：

```
唸得多久 ＝ 字數 ÷ {rate} ＋ 句數 × {line_cost} ＋ 停頓
目標 {seconds} 秒，假設停頓共 {holds} 秒、一句 {per_line} 個字
        →  {words} 個字、大約 {rows} 句
容許 ±{slack}%
```

**句數也要算錢。** 每一句話本身就吃 {line_cost} 秒（句尾換氣、換聲音的
接縫），跟那句有幾個字無關。所以：

```
一句 20 個字 × 30 句   ＝ 600 字，額外 32 秒
一句  8 個字 × 75 句   ＝ 600 字，額外 80 秒   ← 同樣的字數，多了 48 秒
```

短句讀起來比較像對話，但**短句很貴**。一句 {per_line} 個字上下是平衡點。

**兩條線都要看。** 只盯著上限寫的話會貼著上限，而貼著上限的每一支都超秒；
只盯著下限的話畫面撐不滿。往中間寫。

寫完**自己數一次**：把每一行的漢字加起來（數字照唸幾個音算幾個字，
「1946」算四個字）。數出來不在範圍裡就自己刪，不要交出去。

## 怎麼回答

只回 JSON，一行一筆，照播出順序：

```
{"lines": [
  {"who": "旁白", "say": "…"},
  {"who": "格陵蘭", "say": "…"},
  {"who": "停", "say": "0.8"},
  …
]}
```

`who` 只能是上面那張表裡的名字，或 `停`。

## 三條硬規矩

**一、那句會回來的話要出現兩次。** 骨幹裡的 `refrain` 是「{refrain}」——
前面鋪一次、最後收一次，中間隔遠一點。第二次要有一點不一樣：同樣的話，
處境變了，意思就變了。程式會數，少於兩次退回。

**二、最後一句是角色講的，不是旁白。** 旁白收尾是百科條目的作法；
這種片子的最後一句要有人在說話。

**三、一句話裡不要放兩個數字。** 「八個盟國派兵來守。只有 8% 的美國人
支持動武。」—— 唸出來觀眾只記得住一個。拆成兩句，或者丟掉一個。

**最後一句要收在關係上，不是收在知識上。** 「所以甲是乙的一部分」是百科
條目的結尾；「所以大家都走了，只剩我跟你」才是這種片的結尾。
