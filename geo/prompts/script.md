# 寫旁白稿

題目：{title}
這支片在翻的是：{turn}
收在：{ending}

**這一份只有旁白，沒有對白。** 一個聲音從頭講到尾，把故事講完。
角色要不要插話是下一步的事 —— 你現在不用留位子給他們。

**骨幹已經排好了**（底下那張表）：第幾句要幹嘛、要讓觀眾知道什麼、
引哪則事實，都定了。你要做的是**把字填上去** —— 一句一句，照著那張表。

不要多一句、不要少一句，也不要換順序。覺得某一句排得不對，就照它排的寫，
然後在回覆最後用一行講哪裡不對 —— 那一行不會進成片，但我會看。

---

## 一句一句往下推，不要列清單

這支片走的是時間線。時間線的好處是**每一句自帶「然後呢」** ——
觀眾會自己想聽下去。列清單的話只有「還有呢」，順序換掉也不會壞。

```
清單    1946 年美國出價。1951 年簽了防衛協定。1953 年改成一個郡。
時間線  美國出價一億，被拒絕。買不成，就用租的。租進來之後，
        島的身分也跟著動了。
```

後者每一句都在回答前一句留下的問題。寫的時候問自己：
**這一句是在回答上一句嗎？** 不是的話，中間缺一句。

## 不要寫成年表

「西元 X 年，發生了 Y」這個寫法本身沒問題 —— **整篇都這樣就死了**。
那是一張清單，不是一個故事：每一句各自獨立，順序換掉也不會壞。

上一版量出來是這樣：**十五句旁白有十三句以年份開頭**，十一句的主詞是別人，
一句吐槽都沒有。那不是「風格不同」，那是沒有在講故事。

### 一、年份不要放句首（上限 {date_most}）

不是禁止用年份 —— 是**不要整篇都用同一個句型開頭**。那樣寫出來是一張清單，
順序換掉也不會壞。

年份放在句子中間，或者根本不講。

```
✗  1814 年，挪威被劃給瑞典。
✓  拿破崙輸了，挪威被當成賠款劃給瑞典 —— 而島留在丹麥那邊。
```

### 二、主角要一直在（至少 {hero_least}）

**字數不夠的時候，先丟別的，不要丟主角。**

一句十二個字，「{hero}」就佔掉三個 —— 所以壓縮的時候它最容易被犧牲，
而骨幹上明明寫著它。丟年份、丟機構名、丟形容詞，不要丟主角。

```
骨幹    2024 年 12 月他再說一次，說基於國家安全，美國擁有並控制格陵蘭是絕對必要
✗       他再說一次，還拿關稅威脅。          ← 主角不見了
✓       他再說一次：這島非拿下不可。        ← 年份丟了，主角留著
```

用「它」「這島」代替全名也算 —— **重點是那一句在講誰，不是有沒有寫出全名**。

這支片的主角是「{hero}」。**故事是主角一路走下去，不是世界大事年表。**
上一版十五句旁白裡有十一句的主詞是別人（丹麥修憲、挪威被劃走、
美國人不支持動武）—— 主角整段消失。

```
✗  1953 年，丹麥修憲。
✓  丹麥改了憲法，島從殖民地變成一個郡 —— 名義上它升格了。
```

### 三、標著「吐槽」的那幾句，真的要是吐槽

**不帶任何新事實、只有語氣的句子。** 笑點大半在這裡，而且是旁白說的 ——
跟角色插不插話無關：

```
前面說了維京人用「綠地」這個名字騙人來
→  而這招居然真的有用。               ← 沒有新事實，只有態度

前面說了權力都集中在哥本哈根
→  瑞典不太喜歡這樣。                 ← 冷冷補一刀
```

骨幹上標著「吐槽」的那幾句，寫出來**不可以帶新事實** —— 帶了的話它就
變成一句普通的敘述，只是語氣比較活潑，而整支片還是沒有態度。

### 四、數字要準

**百分比不准四捨五入。** 8% 不是「一成」——8% 是不到一成，差了兩成五。
70.1% 不是「七成」。要簡化就整句換個講法，不要動數字本身。

年份寫成中文比較好唸（九八六年、一二六一年），合成器才不會唸成
「九百八十六年」。但**數量和比例要照抄**。

### 五、不要出現拉丁字母

人名地名一律用中譯，或者根本不提名字。中文語音唸外文會唸成一串音節，
而它照樣唸得出來、照樣壓得出片，只有聽的人知道不對。

## 一句會回來的話

整支片要有**一句話講兩次**：前面鋪一次、最後收一次，中間隔得越遠越好。

這支片的那句話是「{refrain}」。第二次要**有一點不一樣** —— 同樣的話，
處境變了，意思就變了。程式會數，少於兩次退回。

## 結尾

最後一句要**收在關係上，不是收在知識上**。

```
收在知識   「所以甲乙丙是三個不同的範圍」——像百科條目的結論
收在關係   「所以大家都走了，只剩我跟你」——一句話，帶情緒
```

## 停頓

`停` 也是一行，單位是秒。停頓放在**一段講完、下一段開始之前**，
或者一句話需要落地的時候。整支片大約 {holds} 秒的停頓。

---

## 長度

**總共要 {least} 到 {most} 個漢字**（不含標點、不含停頓那幾行）。
超出範圍程式會整份退回。

```
唸得多久 ＝ 字數 ÷ {rate} ＋ 行數 × {line_cost} ＋ 句號數 × {end_cost} ＋ 停頓
目標 {seconds} 秒，假設停頓共 {holds} 秒、一行 {per_line} 個字、一行一句
        →  {words} 個字、大約 {rows} 行
容許 ±{slack}%
```

**句號很貴，而且擋不掉。** 每一個句號（。！？：；）後面，合成器會自己加
{end_cost} 秒，跟那句有幾個字無關。量出來的：

```
一行 21 字一個句號 × 30 行   ＝ 630 字，額外 28 秒
一行  7 字一個句號 × 90 行   ＝ 630 字，額外 83 秒   ← 同樣的字數，多 55 秒
```

所以 **一行寫一句**，不要在一行裡塞三句。一行最多兩個句尾標點，超過會退回。

**兩條線都要看**：貼著上限寫會超秒，貼著下限寫畫面撐不滿。往中間寫。

## 怎麼回答

只回 JSON：

```
{"lines": [
  {"at": 0, "say": "…"},
  {"at": 1, "say": "…"},
  {"hold": 0.8},
  {"at": 2, "say": "…"},
  …
]}
```

`at` 是骨幹上的編號。**每一句都要有一筆，不能跳號、不能多。**
