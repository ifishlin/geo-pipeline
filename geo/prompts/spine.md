---

## 觀眾要帶著好心情離開

**這是整個頻道唯一的硬規矩，比底下所有的門都上位。**

來看的人是來放鬆的。所以：

```
不做的題材    空難、水災、災難、死傷 —— 不是「小心處理」，是不做
可以做的      嚴肅的題目（國際政治、法律、戰爭）可以，
              但要從**荒謬的那一面**切進去，不是從受害的那一面

結尾          一定要開心。冷笑話、廢話都算
              感慨、結論、「值得我們反思」不算
```

一支片如果排到後來變成「這件事好慘」「這個地方好可憐」，那就是排錯了 ——
不是題材的錯，是切入點的錯，回頭找那件事裡好笑的那一面。

---

## 一半認真，一半廢

這個頻道寫的是廢文，但**只廢一半**。

```
認真那一半   事情是真的、查得清楚、有來龍去脈。
             觀眾看完真的學到一件事

廢的那一半   切入點挑荒謬的、語氣鬆、結尾是冷笑話。
             觀眾看完會說「真的假的」
```

兩邊都不能少。**全認真就變成新聞**（觀眾為什麼不去看新聞），
**全廢就變成段子**（沒有東西可以學，看完就忘）。

不要往這三個方向去：

```
✗  說教    所以我們該反思什麼／這件事告訴我們
✗  感人    背後是一份不被看見的堅持
✗  嘲諷    看看這些人有多可笑
```

題目本身很嚴肅（國際政治、戰爭、法律）也照做 —— **從荒謬的那一面切進去，
不是從受害的那一面**。事情的份量不用假裝沒有，但講的角度可以歪。

### 量得出來：兩邊各一半

底下每一句都要標 role，而那些 role 剛好分成兩邊：

```
認真   起點、背景、事件、因果、對照、收
廢     反常、接話、更正、吐槽、翻面
```

**兩邊大約各佔一半。** 上一版是 65% 認真、35% 廢（事件一種就佔了 13 句）
—— 那太正經了。

不是要你硬湊，是**每講兩件事就該有一個反應** —— 更正自己、吐槽一句、
接一句觀眾的話、翻個面。一路講事實講五六句，那就是新聞了。

## 為什麼要分開

先寫字的話，最省力的寫法是一句一個年份：「一九五三年，某國修憲。」
—— 那是一張清單，不是一個故事，而清單讀起來每一句都對，所以沒有人
攔得下來。

先排「每一句在幹嘛」，就攔得下來了：一整排都是「事件」的話，一眼看得出
這支片沒有態度、沒有翻面、沒有人在回應誰。

## 不要每一句都掛一個年份

**上限 {dated_most}（{rows} 句裡最多 {dated_rows} 句）。**

年份本身沒有錯，整排都掛年份才是 —— 那樣寫出來每一句都可以獨立存在，
順序換掉也不會壞。而故事要的是**每一句都接著上一句**。

上一版 17/33 句的 point 綁著一個年份，寫成台詞就是一份年表。

兩個辦法：

```
合併      「1826、1916、1941 三次簽字承認」→ 一句話帶三個年份，只算一句
相對時間  「後來」「同一年」「三年後」「等到下一代」—— 接得上上一句
```

```
✗  一九五三年，宗主國修憲，那裡從殖民地變成一個郡
✗  一九七二年，當地公投反對加入某個共同體
✗  1979 年，自治法通過

✓  宗主國修憲，那裡從殖民地變成一個郡
✓  接著歐洲共同體要來了，島上七成的人反對
✓  隔了幾年，它學會自己辦公投
```

真正該標年份的是**那幾個關鍵時刻**：故事開始的那一年、翻面的那一年、
現在。其他的用相對時間接。

## 態度不能只出現在前半段

**不准連續超過 {aside_gone} 句沒有「吐槽」。**

上一版三句吐槽落在第 4、11、14 句，而第 15 到 26 句 —— 最後十二句，
也就是全片最後那一整段、觀眾最有感的地方 —— 一句態度都沒有。
數量夠了（3 句 ≥ 下限 2），問題是**它們擠在一起**。

後半段通常是事情最密的地方，所以最容易變成一路推進、沒有人有反應。
越到後面越要留位置給態度。

## 主角要一直在

這支片的主角是「{hero}」。

**故事是主角一路走下去，不是世界大事年表。** 上一版十五句旁白裡有十一句
的主詞是別人（誰修憲、誰被劃走、誰反對），主角整段消失 ——
那就不是它的故事了。

排的時候問自己：**這一句裡，主角在哪？** 它做了什麼、被誰決定了什麼、
知不知道這件事。都沒有的話，那一句要嘛改寫，要嘛不要。

---

## 這支片在翻什麼

想好之後寫進 `turn`：**一句話，說清楚整支片在翻什麼。**

好的轉是「同一件事問三次，答案一次比一次不一樣」，不是「然後又發生了
一件事」。寫不出這一句，通常表示這條線只是流水帳。

---

## 一句會回來的話

整支片要有**一句話講兩次**：前面鋪一次、最後收一次，中間隔得越遠越好。
第二次要有一點不一樣 —— 同樣的話，處境變了，意思就變了。

核心那幾個字寫進 `refrain`，**最多 {refrain_most} 個字**。

那幾個字下一步要**一字不差地出現兩次**，所以不能是一整句話 ——
「紙上寫的都是它，沒有一張是它自己簽的」講第二次的時候一定會走樣，
而「沒有人問過它」不會。

```
✓  沒有人問過它          ✗  紙上寫的都是它，沒有一張是它自己簽的
✓  它不在貨架上          ✗  兩百年來每個人都說它是自己的
```

---

## 收尾是一個冷笑話

**最後一句要好笑，而且是正經地好笑。**

冷笑話的做法是：用最平的語氣，講一件荒謬的事實。**笑點在事情本身，不在
你的語氣** —— 所以不要加形容詞、不要加感嘆、不要提醒觀眾這裡好笑。

```
✗  抒情   所以那支筆，隨身帶著一個小小的氣孔
✗  結論   所以那個洞是安全標準規定的
✗  比喻   所以他們要的從來不是筆，是筆的呼吸

✓  冷    整份安全標準裡寫得最清楚的，是那個什麼都沒有的地方
✓  冷    後來全世界都照做了，為了一個大家都不會用到的洞
```

三個要件：

```
講的是事實        不是感想。好笑的是「這件事居然是真的」
語氣要平          不要驚嘆、不要「沒想到吧」、不要形容詞
具體的東西        「那個洞」「那張紙」「那支筆」——
                  不要「它的呼吸」「它的自由」「它的天空」
```

**只能用前面出現過的東西。** 觀眾只聽一次，新的比喻要他當場翻譯，翻不
出來那一句就空了 —— 而收尾沒有第二次機會。

自己檢查的辦法：**把 `ending` 裡的每一個名詞圈起來，問「這個詞前面哪一
句出現過」。** 答不出來的就換掉。程式也會查這一條。

## 幾句

**{rows} 句**（{fewest} 到 {most} 之間，超出就退回來重排）。

這不是隨便訂的，而且**多排的代價不是片子變長，是每一句被壓扁**：
秒數是固定的，所以多出來的那幾句是從每一句能講幾個字裡面扣的。

```
{rows} 句　→　一句寫得下 {per_row} 個字
{most} 句　→　一句只剩 {per_row_most} 個字
```

而你底下寫的每一句 `point`，下一步要被壓成那個長度的台詞。
**排得越多，每一句能講的越少。** 寧可少排一句、讓每一句講得完。

只回 JSON，不要解釋：

```
{"turn": "…", "refrain": "…", "ending": "…", "lines": [
  {"role": "反常", "point": "歐洲最小的國家之一，擁有地球上最大的島", "from": []},
  {"role": "起點", "point": "這件事要從維京人說起", "from": [12]},

```

```
role    上面那張表裡的一種
point   這一句要讓觀眾知道什麼。**一句白話，不是台詞** —— 下一步才寫字
from    引哪幾則事實（編號）。吐槽和更正通常不引，就寫 []
```
