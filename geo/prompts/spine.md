## 為什麼要分開

先寫字的話，最省力的寫法是一句一個年份：「1953 年，丹麥修憲。」
—— 那是一張清單，不是一個故事，而清單讀起來每一句都對，所以沒有人
攔得下來。

先排「每一句在幹嘛」，就攔得下來了：一整排都是「事件」的話，一眼看得出
這支片沒有態度、沒有翻面、沒有人在回應誰。

## 不要每一句都掛一個年份

**上限 {dated_most}（{rows} 句裡最多 {dated_rows} 句）。**

年份本身沒有錯，整排都掛年份才是 —— 那樣寫出來每一句都可以獨立存在，
順序換掉也不會壞。而故事要的是**每一句都接著上一句**。

上一版 17/33 句的 point 綁著一個年份，寫成台詞就是一份年表。

兩個辦法：

```
合併      「1826、1916、1941 三次簽字承認」→ 一句話帶三個年份，只算一句
相對時間  「後來」「同一年」「三年後」「等到下一代」—— 接得上上一句
```

```
✗  1953 年，丹麥修憲，島從殖民地變成一個郡
✗  1972 年，格陵蘭公投反對加入歐洲共同體
✗  1979 年，自治法通過

✓  丹麥修憲，島從殖民地變成一個郡
✓  接著歐洲共同體要來了，島上七成的人反對
✓  隔了幾年，它學會自己辦公投
```

真正該標年份的是**那幾個關鍵時刻**：故事開始的那一年、翻面的那一年、
現在。其他的用相對時間接。

## 主角要一直在

這支片的主角是「{hero}」。

**故事是主角一路走下去，不是世界大事年表。** 上一版十五句旁白裡有十一句
的主詞是別人（丹麥修憲、挪威被劃走、美國人不支持動武），主角整段消失 ——
那就不是它的故事了。

排的時候問自己：**這一句裡，主角在哪？** 它做了什麼、被誰決定了什麼、
知不知道這件事。都沒有的話，那一句要嘛改寫，要嘛不要。

---

## 這支片在翻什麼

想好之後寫進 `turn`：**一句話，說清楚整支片在翻什麼。**

好的轉是「同一件事問三次，答案一次比一次不一樣」，不是「然後又發生了
一件事」。寫不出這一句，通常表示這條線只是流水帳。

---

## 一句會回來的話

整支片要有**一句話講兩次**：前面鋪一次、最後收一次，中間隔得越遠越好。
第二次要有一點不一樣 —— 同樣的話，處境變了，意思就變了。

核心那幾個字寫進 `refrain`，寫台詞那一步會去數。

---

## 收在關係上，不是收在知識上

```
收在知識   「所以甲乙丙是三個不同的範圍」——像百科條目的結論
收在關係   「所以大家都走了，只剩我跟你」——一句話，帶情緒
```

只回 JSON，不要解釋：

```
{"turn": "…", "refrain": "…", "ending": "…", "lines": [

  {"role": "起點", "point": "這件事要從維京人說起", "from": [12]},
  {"role": "更正", "point": "其實島上早就有人住了", "from": [3]},

```

```
role    上面那張表裡的一種
point   這一句要讓觀眾知道什麼。**一句白話，不是台詞** —— 下一步才寫字
from    引哪幾則事實（編號）。吐槽和更正通常不引，就寫 []
```

{count} 則事實不必全部用上。**用不到的比硬塞進去好。**
