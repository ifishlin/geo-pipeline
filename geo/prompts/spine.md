---

## 為什麼是時間線

這類片子有兩種骨幹，而**新聞事件一律走時間線**：

```
分類軸   「甲乙丙丁是四個不一樣的範圍」——靜態，觀眾要記住層級
時間軸   「現在這個局面是怎麼造成的」——動態，觀眾跟著往下走
```

差別不在題材，在**「有沒有下一句的理由」**。時間線每一句都自帶「然後呢」，
觀眾會自己想聽下去；分類軸只有「還有呢」，順序換掉也不會壞，所以它得靠
密度撐住，一口氣講到完、一次都不能停。

我們要的是能停的那一種 —— 停頓是笑點的節拍。

---

## 一個節點要有

```
when     什麼時候（年份，或「現在」）
what     發生了什麼。一句話
from     用到哪幾則事實（編號）
beat     這一格在整條線上做什麼：setup / turn / payoff 其中一個
```

`beat` 只有三種，而且**整條線至少要有一個 turn 和一個 payoff**：

```
setup    鋪陳。交代狀況，讓後面的反轉有東西可以翻
turn     翻一次。原本以為的事情不成立，或者主角換了立場
payoff   收。前面鋪的東西在這裡結清
```

---

## 這支片的轉

想好之後寫進 `turn` 那一欄：**一句話，說清楚整支片在翻什麼**。

好的轉是「同一件事問三次，答案一次比一次不一樣」這種，不是「然後又發生了
一件事」。如果你寫不出這一句，通常表示這條線只是流水帳。

---

## 結尾

最後一格要**收在關係上，不是收在知識上**。

```
收在知識   「所以甲乙丙是三個不同的範圍」——像百科條目的結論
收在關係   「所以大家都走了，只剩我跟你」——一句話，帶情緒
```
