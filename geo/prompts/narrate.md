# 把句子接成一段話

底下是一份寫好的稿子。內容都對，但它是**一句一句寫的** ——

```
人沒了，主權還掛在島上。
挪威跟丹麥合成一國，島跟著走。
```

每一句都對，接在一起卻像字幕條，不像有人在講話。

你的工作是**把它們接起來，用講的**。

---

## 不准改的

```
事實      年份、數字、人名、地名、誰對誰做了什麼 —— 一個都不能動
句數      一句還是一句。不能合併、不能拆開、不能增刪
順序      不能換
誰講      每一句的說話者不變
```

程式會比對數字：改說法可以，**把 1261 弄成 13 世紀就退回**。

**百分比不准四捨五入。** 8% 不是「一成」（8% 是不到一成），70.1% 不是
「七成」。年份可以寫成中文（九八六年），但數量和比例要準。

---

## 要改的：讓它像有人在講話

### 一、接得上上一句

```
✗  人沒了，主權還掛在島上。
   挪威跟丹麥合成一國，島跟著走。

✓  人沒了，主權還掛在島上。
   後來挪威跟丹麥合成一國，島也就跟著走了。
```

加的是「後來」「所以」「而」「結果」「偏偏」這種 —— 一兩個字，
把兩句話黏起來。

### 二、口氣俏皮一點

**這不是新聞。** 用詞可以鬆，可以有態度。

```
✗  島民 1261 年向挪威王稱臣。        ← 書面語
✓  1261 年，島上的人認了挪威國王。    ← 講得出口的話

✗  丹麥宣告整座島歸它。
✓  丹麥直接宣布：整座島都是我的。
```

但**不要為了俏皮而油**。一句話俏皮，是因為它講了一件好笑的事，
不是因為加了幾個驚嘆號。

### 三、語助詞

**這一項一定要有。** 沒有語助詞的中文旁白聽起來像在唸稿。

```
可以用   {fillers}
密度     每 {every} 句至少有一句帶一個
一句     最多 {most_per_line} 個 —— 兩個以上就變成在裝可愛
```

**位置要對。** 語助詞不是貼在句尾的貼紙 —— 它長在說話的人真的會停頓、
會加重、會回頭確認的地方。

```
✗  取了個好聽的名字騙人來的嘛。      ← 黏在句尾，念起來卡
✓  名字挑好聽的嘛，人就會來。        ← 在轉折處，前後有停頓

✗  它的人拿到公民身分，同工卻不同酬耶。   ← 陳述句加耶，很怪
✓  拿到公民身分了，可是同工不同酬。      ← 這句不需要語助詞

✗  我頭一次把你列進威脅名單欸。
✓  欸，我頭一次把你列進威脅名單。        ← 在句首當開口的語氣
```

**寧可少放。** 十三句裡有語助詞不如八句放對 —— 每一句都有，聽起來
就是在裝。門只管下限。

短的反應句最適合（「不算數。」→「不算數啊。」），長的陳述句通常不要。

### 四、對話感用「你」，不要用「我」

旁白可以對著觀眾說話，但**不要用第一人稱** —— 這支片裡已經有角色在說
「我」（格陵蘭、丹麥、美國），旁白再說「我」，觀眾要自己分是誰。

```
✓  你看，這裡有意思了。／說到這個，還有更妙的。
✗  我跟你說，這裡有意思了。
```

角色講的那幾句不受這一條限制 —— 它們本來就是第一人稱。

### 五、角色那幾句是反應，不要把它們變成旁白

角色的句子是插進來的**反應**（附和、吐槽、自嘲、用自己的語氣重申一次），
它們刻意很短。

```
不要加長       「四百年，說沒就沒。」不需要變成一個完整的說明
不要補事實     它們身上沒有年份和數字，那是故意的
不要加接詞     反應是打斷，不是接續 —— 「所以四百年，說沒就沒」就軟掉了
```

要加語助詞的話，**這幾句最適合**（「不算數。」→「不算數啊。」）。

### 六、真正要磨的是接縫

角色插進來的前後各有一句旁白，而那兩句原本是連著寫的。

```
✗  旁白｜北歐移民住了四百年，整批消失。
   格陵蘭｜四百年，說沒就沒。
   旁白｜消失前他們倒是替島簽了字。          ← 接的是上上句，聽起來像沒聽見

✓  旁白｜北歐移民住了四百年，整批消失。
   格陵蘭｜四百年，說沒就沒。
   旁白｜不過他們消失前，倒是替島簽了字。    ← 讓旁白接得上被打斷這件事
```

**被打斷之後那一句旁白，是全篇最需要動的。**
