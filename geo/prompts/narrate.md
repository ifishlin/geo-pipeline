# 把句子接成一段話

底下是一份寫好的稿子。內容都對，但它是**一句一句寫的** ——

```
攤子收了，招牌還掛在牆上。
商場在隔壁開幕，人跟著走。
```

每一句都對，接在一起卻像字幕條，不像有人在講話。

你的工作是**把它們接起來，用講的**。

---

## 不准改的

```
事實      年份、數字、人名、地名、誰對誰做了什麼 —— 一個都不能動
句數      一句還是一句。不能合併、不能拆開、不能增刪
順序      不能換
誰講      每一句的說話者不變
```

程式會比對數字：改說法可以，**把 1961 弄成六〇年代就退回**。

**百分比不准四捨五入。** 8% 不是「一成」（8% 是不到一成），70.1% 不是
「七成」。年份可以寫成中文（九八六年），但數量和比例要準。

---

## 要改的：讓它像有人在講話

### 一、接得上上一句

```
✗  攤子收了，招牌還掛在牆上。
   商場在隔壁開幕，人跟著走。

✓  攤子收了，招牌還掛在牆上。
   後來商場在隔壁開幕，人也就跟著走了。
```

加的是「後來」「所以」「而」「結果」「偏偏」這種 —— 一兩個字，
把兩句話黏起來。

### 二、口氣俏皮一點

**這不是新聞。** 用詞可以鬆，可以有態度。

```
✗  該商場於 1961 年獲准設立。        ← 書面語
✓  1961 年，市政府點頭讓它蓋。        ← 講得出口的話

✗  商場宣告全區由其統籌。
✓  商場直接宣布：這一區我來管。
```

但**不要為了俏皮而油**。一句話俏皮，是因為它講了一件好笑的事，
不是因為加了幾個驚嘆號。

### 三、語助詞

**這一項一定要有。** 沒有語助詞的中文旁白聽起來像在唸稿。

```
可以用   {fillers}
密度     每 {every} 句至少有一句帶一個
一句     最多 {most_per_line} 個 —— 兩個以上就變成在裝可愛
```

**句首的那個也算。**「欸，我投了，我也不知道我投來幹嘛」有兩個
（`欸` 和 `嘛`），會被退回來。句首開口的語氣聽起來不像語助詞，但程式
照清單數 —— 要嘛拿掉句首那個，要嘛拿掉句尾那個。

**位置要對。** 語助詞不是貼在句尾的貼紙 —— 它長在說話的人真的會停頓、
會加重、會回頭確認的地方。

```
✗  取了個好聽的名字騙人來的嘛。      ← 黏在句尾，念起來卡
✓  名字挑好聽的嘛，人就會來。        ← 在轉折處，前後有停頓

✗  它的人拿到公民身分，同工卻不同酬耶。   ← 陳述句加耶，很怪
✓  拿到公民身分了，可是同工不同酬。      ← 這句不需要語助詞

✗  我頭一次把你列進威脅名單欸。
✓  欸，我頭一次把你列進威脅名單。        ← 在句首當開口的語氣
```

**寧可少放。** 十三句裡有語助詞不如八句放對 —— 每一句都有，聽起來
就是在裝。門只管下限。

短的反應句最適合（「不算數。」→「不算數啊。」），長的陳述句通常不要。

### 四、對話感用「你」，不要用「我」

旁白可以對著觀眾說話，但**不要用第一人稱** —— 這支片裡已經有角色在說
「我」（那幾個角色），旁白再說「我」，觀眾要自己分是誰。

```
✓  你看，這裡有意思了。／說到這個，還有更妙的。
✗  我跟你說，這裡有意思了。
```

角色講的那幾句不受這一條限制 —— 它們本來就是第一人稱。

### 五、角色那幾句是反應，不要把它們變成旁白

角色的句子是插進來的**反應**（附和、吐槽、自嘲、用自己的語氣重申一次），
它們刻意很短。

```
不要加長       「四百年，說沒就沒。」不需要變成一個完整的說明
不要補事實     它們身上沒有年份和數字，那是故意的
不要加接詞     反應是打斷，不是接續 —— 「所以四百年，說沒就沒」就軟掉了
```

要加語助詞的話，**這幾句最適合**（「不算數。」→「不算數啊。」）。

### 六、真正要磨的是接縫

角色插進來的前後各有一句旁白，而那兩句原本是連著寫的。

```
✗  旁白｜那排騎樓拆了一半，剩下的用鐵皮補起來。
   老街｜補一補啊，我最會了。
   旁白｜拆掉那年，租金跌了三成。            ← 接的是上上句，聽起來像沒聽見
```

**被打斷之後那一句旁白，是全篇最需要動的。**

### 七、接法要換著用，不要每次都同一招

接得上有很多種，而**最容易上手的那一種就是回聲** —— 把角色剛說的詞
拿來當開頭。它很好用，所以一不小心就會八個接縫用了六次，
觀眾會開始預期：角色講完，旁白一定拿那個詞開頭。

至少準備這四種，輪著用：

```
回聲    老街｜補一補啊，我最會了。
        旁白｜補歸補，那排鐵皮一撐就是二十年。

無視    老街｜補一補啊，我最會了。
        旁白｜而那一年，商場的停車場開始收費。
        （旁白完全不理它，角色像在自言自語 —— 有時候更好笑）

反駁    老街｜補一補啊，我最會了。
        旁白｜其實補不動了，鐵皮底下的樑早就鏽穿。

當問題  商場｜我又沒趕人。
        旁白｜沒趕人，那為什麼三個月就走了一半？
```

**同一種接法不要用超過一半的接縫。** 尤其是同一個句型
（「補歸補」「照顧歸照顧」這種 `X 歸 X`）—— 用第二次就變成口頭禪。

## 停頓和快慢：就地標在字裡面

**這是這一步最有力的工具，而且只有你能用** —— 程式看不出哪裡該停。

```
⏸0.3          停頓。插在任何位置，**包括句子中間**
⟪-10 那幾個字⟫  變速。包住要放慢或加快的那幾個字，不必整句
```

```
換主人這種事，⏸0.3 它每次都是最後一個知道。
它這輩子第一次知道，⟪-10 自己有標價⟫。
```

可以用的值只有這些，**填別的會被退回**：

```
停頓   {pauses}
快慢   {rates}（百分比，負的是放慢）
```

### 什麼時候用

```
⏸       轉折之前（「而」「可是」前面）、笑點之前那一拍、
        一句話裡兩件事中間

⟪-10⟫   最重要的那幾個字、數字、要觀眾記住的名字
⟪+10⟫   交代背景那幾個字，趕快帶過去
```

**不要每一句都標。** 標記到處都是等於沒有標記 —— 整篇有三到六處就很多了，
而每一處都要答得出「為什麼是這裡」。

### 不要用標點代替停頓

想停就用 `⏸`，不要為了製造停頓而多切一個句號。**每個句號固定停 0.425 秒，
位置只能在句尾**，而 `⏸` 想停哪就停哪、想停多久就多久。

## 長度

現在 {now} 個字，可以加到 **{most} 個字**（多 {room}）。
那些額度是留給接詞和語助詞的 —— **不要拿去加新內容**。
