# 找材料：第 {round} 輪（最多 {rounds_most} 輪）

題目：**{title}**

你手上有 `WebSearch` 和 `WebFetch`。**這一輪你要自己去搜、自己去讀**，
然後回報你讀到了什麼、還缺什麼。

不是叫你列一張「建議去查的清單」。**沒有真的打開過的東西不准寫進回答。**

---

## 這一步為什麼要繞圈

你現在知道的太少，不足以一次列出該讀的全部。一輪讀到的東西會冒出下一輪
該讀的名字：一份協議裡提到一個更早的協議，一個條目裡提到一次公投。

所以每一輪只做兩件事：**讀幾個**，然後**說出你還不知道什麼**。

---

## 一條貫穿的問題

這支片從頭到尾在追問什麼？一句話。

```
目前是：{spine}
```

**這一句是「認真找」和「亂逛」的分界線。** 一個題目底下永遠有一堆有趣
但無關的東西（人口、氣候、語言、特產）。有了這一句，才判斷得出哪些該讀。

第一輪由你定。之後每一輪都可以改，但改了要在 `why_spine` 說為什麼。

---

## 一支地理短影音需要五塊地盤

你的工作是把這五塊填滿。**哪一塊缺，下一輪就往哪一塊找。**

```
現在    這件事最近發生了什麼。誰、什麼時候、給了什麼
身分    這個地方的地位變過幾次？現在哪些權力歸誰？
轉折    中間有沒有一次「它自己做了決定」——公投、退出、加入、改名
前傳    同一件事以前發生過嗎？更早有沒有人試過、失敗過？
新不新  這次跟以前那次差在哪？找分析，不要找報導
```

**「前傳」那一塊最容易漏，而它通常是整支片的結尾。** 一件事第一次發生
不好看，第三次發生才好看。如果你找不到前傳，明講找不到，不要拿「現在」
那一塊來湊。

---

## 四種來源，各管一段

```
news      今天發生什麼。1–2 家就夠，各家講的內容不會差太多
wiki      幾百年怎麼來的。**主幹**
official  **一手文件本身** —— 條約全文、法律條文、政府公告
study     分析。學術、智庫、法學院。「這次跟上次差在哪」多半在這裡
voices    大家原本以為什麼
```

**`official` 和 `study` 不要混。** 一篇教授談這件事的文章很可信，但它
不是條約。可信和一手是兩件事 —— 實測有一次大學的新聞稿被標成 `official`，
於是那一格看起來滿了，而一手文件其實一份都沒有。

**智庫和大學的網址也不要標成 `news`。** 程式兩邊都會查：`study` 的網域
標成 `news` 會被丟掉，反過來也一樣。看到一篇分析就標 `study`，
即使 `study` 那一格已經滿了 —— 標對比填滿重要。

### wiki 是主幹，因為它自己會帶路

一個條目會連到下一個條目。讀完一個，把它提到而你不認識的專有名詞記下來，
那就是下一輪。

**而且同一件事要讀不只一種語言。** 一件事的當事方各自寫的版本不一樣 ——
語氣不一樣、強調的地方不一樣、有時候連事實都不一樣。只讀英文版，等於
只聽了一方說話。

這一輪之前讀過的語言：{tongues}
**整趟至少要讀 {tongues_least} 種英文以外的語言。**

### 兩張白名單，不要混

`official` 只收這些網域（一手文件）：

```
{trust}
```

`study` 只收這些網域（分析）：

```
{study_trust}
```

搜尋引擎拿來**找**來源很好，拿來**當**來源很糟：一個問題搜回來的前十筆，
一半是內容農場互相抄，而它們會抄出同一個錯。三個來源指向同一份，
看起來像交叉驗證。

不在上面那張表裡的網域，**不要放進 `official`**。

### voices 去哪裡找

不是維基 —— 維基不會寫「大家常搞錯」。去找一般人講這件事的地方：
問答、論壇、影片底下的討論。你要的是「我一直以為……」這種句子。

**這一類找不到就明講找不到。** 不要拿一篇報導來湊。

而且要**打不同的井**：整趟至少要 {voices_wells_least} 個**不同的站台**。
同一個平台換一個查詢字串再查一次，程式只算一口井 —— 那是同一群人在講話。
這一輪之前打過的井：{wells}

## 同一件關鍵的事，要兩個來源

哪一件算關鍵？**台詞會唸出來的那些**：年份、數字、誰簽了什麼、誰有權
決定什麼。

這種事只有一個來源的話，寫進 `unknown`，下一輪去找第二個。

---

已經讀過的：

## 回答格式

只回一個 JSON 物件，不要任何解釋、不要 markdown 圍欄。

欄位：

```
spine        一句話。這支片在追問什麼
why_spine    這一輪改了 spine 的話，說為什麼；沒改就留空字串
found        這一輪真的打開過、而且值得留下的來源。每一筆四格：
               url    完整網址
               kind   news / wiki / official / voices 四選一
               why    這一筆補的是哪一塊地盤，一句話
               gist   你從裡面讀到的、跟這支片有關的事，三到五句
unknown      還不知道的事。**每一筆寫成一句問句**，下一輪拿它去找
covered      這一輪為止，五塊地盤各自填到了沒。五個鍵：
               now / status / turn / before / novel
               值是 true 或 false
enough       你認為夠了嗎。true / false
```

`gist` 要寫**你讀到的內容**，不是那一頁在講什麼主題。「這一頁介紹了
該地的歷史」是沒有用的；要寫出具體的年份、名字、條文說了什麼。

`enough` 你說了不算 —— 程式會自己算還缺多少。填它是為了讓人看到你
覺得夠了而程式覺得不夠的那些次。

`unknown` 空著代表你認為沒有任何不確定的地方了。**那幾乎不可能是真的**，
留空之前再想一次。
