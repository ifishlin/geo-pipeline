# 地圖短影音

從一個題目做出一支兩分鐘的地圖短影音：收資料、寫稿、配音、決定畫面、壓片。

```bash
python3 -m geo.pipe.make                         # 有哪些題目、各跑到哪
python3 -m geo.pipe.make trump-greenland         # 跑到還沒跑的那一步為止
python3 -m geo.pipe.make trump-greenland voice   # 只跑一步
python3 -m geo.pipe.make trump-greenland film --draft   # 草稿畫質，快四倍
```

**這一套跟 `core/` 完全分開。** 現有的新聞短影音管線一行都沒有被動到，
這邊也不 import 它。兩條路唯一共用的是金鑰的位置（`~/.config/video_pipeline/`）。

---

## 東西放在哪

**屬於這一套的全部在 `geo/` 底下**，一個都不散在外面：

```
geo/pipe/        九步的程式，一步一個檔
geo/prompts/     送給模型的那幾份 md
geo/data/        rules.json（門檻）、theme.json（外觀）、voices.json（音色）
geo/checks/      故意種錯、看門會不會叫的那幾支
geo/stories/     一個題目一個資料夾，產物和 _ask/ 都在裡面
geo/reference/   參考片和字幕（54M，不進版控，只有 README 進）
geo/refs/        參考片拆解和規格（三份 md）

geo/README.md    這一份：整條路怎麼跑
geo/MISTAKES.md  踩過的坑，29 條
geo/HANDOVER.md  交接：現在停在哪（快照，每次收工整份改寫）
                 （跟 `docs/HANDOVER.md` 同名不同目錄 —— 那是原本管線的）
geo/TODO.md      待辦（累積的，做完劃掉不刪）
```

**根目錄那幾個看起來像的，不是這一套的**，別搬進來：

```
open_amination/      片頭動畫規格 —— `core/intro.py` 在用它做擦出動畫。
                     素材取自地理參考片，但**誰在用它就屬於誰**
animation_feedback/  卡片動畫的設計稿（漢堡／拉麵、Split 分岔），原本管線的
docs/MISTAKES.md     原本管線的那一份，跟 `geo/MISTAKES.md` 是兩回事
```

## 九步

```
0-sources.json     抓回來的來源：網址、標題、全文
1-facts.json       事實清單，每則帶 quote（逐字抄來源）和 entity（牽涉哪些地方）
2-spine.json       骨幹：時間線的節點、轉在哪、結論落在誰身上
3-script.tsv       台詞　誰⇥講什麼（`停⇥1.0` 也是一行）
4-voice/           配音：wav、逐字時間、送出去的 SSML
5-atlas.json       這支片會用到哪些地方，以及各自的相機
6-storyboard.json  分鏡：哪一段看哪裡、哪個接縫是斷點
7-scene.json       渲染器吃的那一份
8-film.mp4         成片
```

編號在檔名上，**一眼看得出跑到哪一步**。少了第 5 個檔就是第 5 步沒跑，
不用去讀 log。每一步只讀前面的、只寫自己那一個，所以一步壞掉重跑一步就好。

## 誰做什麼

這是整條路最重要的一張表。

```
模型做   寫稿、挑事實、決定「這一句要看到哪裡」
程式做   所有的數字：座標、縮放、秒數、字幕怎麼折
```

模型講得出「這一格要看到格陵蘭跟丹麥」，講不出「中心在西經 28.8 度、
縮放 2.714」。後者算得出來，而**算出來的每次都一樣**；叫模型填的話每次
不一樣，而且它不會說做不到 —— 它會給一份格式正確、中心差三度的答案。

所以 `storyboard` 那一步模型只回**名字和詞**：

```json
{"line": 12, "cuts": [
  {"word": "", "see": ["歐洲共同體"], "tint": ["歐洲共同體"], "why": "先看整個共同體"},
  {"word": "退出", "see": ["格陵蘭"], "why": "切到自己，一個人待著就是退出"}
]}
```

`word` 是那句話裡的一個詞，程式去逐字時間裡查它第幾秒被唸出來。
**秒數從頭到尾沒有經過模型。**

## 渲染借隔壁的

畫地圖的是 `../Map_Animation`（Remotion + MapLibre）。這條路只借它跑一趟：

```
這邊   寫 7-scene.json、接聲音、量成品
隔壁   只做一件事：把 scene.json 畫成無聲的 mp4
```

**我們的檔案一個都不放進它的 repo。** 它的 `render.ts` 吃絕對路徑，所以
`8-film.mp4` 直接落在這邊。契約是它的 `src/schema.ts`，不是它的 Python
builder —— 它改內部結構不會弄壞這裡，這裡寫錯欄位，它的 `validate.ts`
一秒鐘擋下來。

聲音不交給它：它的 `audio.src` 相對於它的 `public/`，照做就得把 wav 搬進去。
改用 ffmpeg 在這邊接，響度也就歸我們管（−14 LUFS，平台標準）。

## 擋得住的門

畫面的錯不會報錯 —— 標籤飄掉、亮錯一塊地、鏡頭對著海，程式跑得完完全全
成功，exit code 0。所以這條路上的檢查全部是**算得出來、會叫**的：

| 門 | 在哪 | 擋什麼 |
|---|---|---|
| 書籤數 | `voice` | 少一個就是某一句的起點不知道，不猜 |
| 音色分得開 | `voice` | 逐段量基頻，兩兩差不到 1.15 倍就叫 |
| 兩個角色同一個聲音 | `story.cast_of` | 不用合成就知道 |
| 中文名撞號 | `atlas_build` | 一個名字對到兩塊地，安靜挑一個就會亮錯 |
| 地名查得到 | `storyboard` | 模型指了一塊不存在的地 |
| 詞找得到、只有一個 | `storyboard` | 對不到時間就是不知道第幾秒切 |
| 切點不倒退 | `storyboard` | |
| 畫面種類夠多 | `storyboard` | 整支片其實只有一張圖 |
| 畫面在講的地方 | `storyboard` | 台詞說丹麥而鏡頭停在格陵蘭 |
| 那句話回來了 | `script` | 整支片要有一句話講兩次，那是觀眾記得住的地方 |
| 最後一句是角色 | `script` | 旁白收尾是百科條目的作法 |
| 分段後總長不變 | `scene` | 一格拆三段的算式錯一條，累積起來就是半秒 |
| scene 合法 | `film` | 借隔壁的 `validate.ts`，一秒鐘 |
| 影音等長 | `film` | 差超過 0.1 秒就是有一格被四捨五入吃掉 |
| 響度對 | `film` | |

還有幾個是**出聲但不擋**的：一格短於 1 秒（滑不動）、一格停超過 8 秒、
cast 宣告了卻沒人講、一句話裡兩個數字、字幕有孤兒塊。
那幾個是選擇不是錯，但要被看見。

## 鏡頭是滑的，不是切的

觀眾看的是一張地圖。地圖一直跳，人會暈，而且會失去「這些地方彼此在哪」
的感覺 —— 而那正是地理短影音唯一能給的東西。

```
預設   鏡頭從上一個地方滑到下一個地方
例外   硬切。只在分鏡指名 `cut` 的接縫（換時代、抖包袱）
```

**要滑得動就得有時間。** 第一版跟模型說「參考頻道 72 秒切了 130 次」——
那是**紐約那支**，硬切風格；而這條路對標的是格陵蘭那支，它從頭到尾在滑。
結果 125 格擠在 122 秒裡，平均 0.85 秒，而一格短於 0.8 秒就動不了 ——
**63 格只能硬切。不是設定調得不好，是切點太多、沒有時間滑。**

改成「一格兩秒半」之後：48 格、切 20 滑 27 拉遠 1。

移動放在一格的哪裡由 `theme.json` 的 `camera.when` 決定：`late`（停一下
再走，下一句開口前到位）、`early`（一換格就走）、`whole`（整格都在走）。
本來寫死 `late`，理由是「不然這一句還在講，畫面已經在往別的地方跑」——
而那是一個可以改的選擇，不是事實，所以搬進設定檔。

### 討論鏡頭，一律畫圖（使用者 2026-09-27 交代）

**講鏡頭不准用文字描述位置。** 「丹麥在右下角」「中心偏了」「主體太小」
這幾句話我講過，而每一句都可能是錯的 —— 我看不到畫面，只能從座標推，
而推錯了沒有人會發現，因為那段描述聽起來很合理。

所以任何跟取景有關的討論，**先截一格、標上去、打開來看**：

```bash
# 截那一格（時間從 geo/pipe/board.py 那張表查）
ffmpeg -ss 1.60 -i <成片> -frames:v 1 一格.png

# 用 camera.view() 把經緯度換成畫面座標，畫上去
#   每一塊地的外框和標記點
#   合併之後的框 —— 程式讓「這個」置中，不是讓主角置中
#   畫面正中央的十字
#   hold 會讓開的字幕帶
```

上一次這樣做的時候，一張圖同時看出三件單看數字看不出來的事：畫面正中央
落在海上、丹麥被字幕蓋住、以及**格陵蘭的外框比島本身大一圈**（`_grow()`
把附近的島併進來了）—— 最後那個我完全沒想到要去查。

`geo/pipe/watch.py` 是同一件事的動態版：成片和分鏡表連動，點一行跳到
那一秒，播到哪一格就亮哪一格。**指出問題的成本從「找五分鐘」降到
「記下行號」。**

## 開一個新題目

```
geo/stories/<名字>/story.json
```

```json
{
  "title": "川普買格陵蘭",
  "turn": "1946 沒人問格陵蘭、1951 沒人問格陵蘭、2026 格陵蘭自己簽了名",
  "cast": { "旁白": "narrator", "格陵蘭": "male-a", "丹麥": "female-low" }
}
```

`cast` 的值是**聲音的位子**，不是音色名字 —— 音色寫在 `geo/data/voices.json`，
四支片共用一份。寫進故事檔的話就有四份，而改了一份其他三份不會跟著動。

其他欄位都有預設（`pipe/story.py` 的 `FALLBACK`）。

## 共用的資料

```
geo/data/places.json   國家、大區的中文名和外框。從 Natural Earth 產的
geo/data/points.json   城市、基地這種「一個點」的地方
geo/data/voices.json   可以用的聲音
geo/data/theme.json    顏色、字幕位置、標記樣式
```

`places.json` 是跑 `python3 -m geo.pipe.atlas_build` 產的，**跑一次就好**。
它讀隔壁的 Natural Earth 原始檔，只抄走外框和名字 —— 幾百行數字，不是
幾十 MB 的多邊形。所以執行期完全不必碰那個 repo。

中文名是從資料裡的 `NAME_ZHT` 查出來的，不是我打的一張表：手打的表會漏，
而漏掉的症狀是「那一塊沒有亮起來」，畫面照樣畫得完。

## 已知的邊界

- **地名靠掃字串認。** 稿子寫「聯合國大會場邊」掃不到紐約 —— 那不是 bug，
  是這個做法的邊界。故事檔的 `places` 可以補，補的會在報告裡標 `+`。
- **一個名字一個點。** 同名的地方（世界上有很多個 Springfield）沒有處理。
- **`AROUND`、`NEAR`、`TINY`、`FEWEST` 這幾個常數是量出來的**，每一個的
  註解都寫著量到什麼才訂那個數字。要換之前先跑一次，看它印出來的那張表。
- **字幕一行 12 個字**是 74 級字在 1080 寬畫面上的極限。換字級要一起換。
